## 3. Desarrollo / Temas tratados

- El PO confirma la necesidad de una plataforma que centralice operación comercial y atención (no un chatbot aislado).
- Se presenta la visión: CRM + cotizador IA + itinerarios + portal del viajero + inteligencia gerencial + marca blanca.
- Se acuerda priorizar un **MVP estable** para pruebas piloto con agencias, orientado a comercialización futura.
- Se revisa la existencia de mockups previos (ecosistema UI) como base de aceptación visual.
- Se define GitHub (`Jeronimo0228/travel-OS`) como herramienta de gestión: Wiki, Issues, Milestones.
- Se discuten integraciones futuras (WhatsApp, pagos, GDS) dejándolas fuera del núcleo del primer piloto salvo stubs.
