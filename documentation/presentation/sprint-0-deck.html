01 · Problemática

Ocho dolores que hoy rompen a la agencia SMB en LATAM

El viajero cotiza con varias agencias a la vez. Quien responde tarde o cotiza lento, pierde el viaje — aunque tenga mejor producto.

1Respuesta lenta = cliente perdido

El lead digital se va con el primero que contesta; demoras de horas matan la conversión.

2Cotizaciones lentas

Tarifas, PDFs, itinerarios a mano y vaivén por WhatsApp: horas. Con IA: minutos.

3Información dispersa

Excel + WhatsApp + correo + Drive + PDFs sueltos. Sin fuente única de verdad.

4Sin seguimiento estructurado

Leads fríos se pierden por falta de nurturing y recordatorios sistemáticos.

5Fuga de conocimiento

Si el asesor se va, se lleva tono, políticas e historial del cliente.

6Trabajo repetitivo

Documentos, requisitos y links administrativos consumen tiempo vendible.

7Métricas opacas

El gerente no ve conversión, CAC, destinos rentables ni desempeño por asesor.

8Inmediatez móvil

El viajero espera WhatsApp/app; el email lento ya no es el canal principal.

Nota de pitch: reforzar con 1–2 cifras del sector (tiempo de respuesta / % leads perdidos).

02 · Solución propuesta

No es un CRM ni un chatbot: es el SO de la agencia

TravelOS AI centraliza ventas, operación y servicio con IA integrada — marca blanca y conocimiento propio por agencia.

Knowledge por agencia

Portal + dashboard

03 · Arquitectura de la solución

Multi-tenant modular, con aislamiento estricto por agencyId

Cada agencia opera en su propio espacio: datos, marca e IA. Lo pesado (PDF, embeddings, emails) corre en colas para que la UI nunca se congele.

Capa 1 · Experiencia

Web agencia + Portal viajero

Next.js 15 + Tailwind. Roles: gerente, asesor y viajero. UI basada en el prototipo Vite ya aprobado.

→
Capa 2 · Dominio

API NestJS multi-tenant

Módulos tipados: CRM, cotizador, itinerarios, tenancy, auditoría. Todo request lleva agencyId.

→
Capa 3 · Plataforma

Datos · Colas · IA

  • PostgreSQL + Prisma (+ pgvector)
  • Redis + BullMQ (async)
  • OpenAI + RAG por agencia
Auth

JWT + RBAC

Asesor, gerente/admin y viajero con permisos explícitos por módulo.

Storage

Object storage

PDFs de cotización, documentos del viaje e itinerarios exportados.

IA aislada

Knowledge por tenant

Políticas, tono y FAQs indexados con filtro obligatorio por agencyId.

Ops

CI + health + audit

Monorepo, GitHub Actions, health checks y trazas de acciones sensibles.

1. Aislamiento real

Sin mezcla de datos ni de conocimiento entre agencias.

2. Async por diseño

PDF/IA/email fuera del request HTTP → UI siempre responsiva.

3. Stack transparente

Arquitectura documentada: diferencial vs cajas negras del mercado.

TypeScript de punta a punta, listo para el MVP y el piloto

Un solo lenguaje en front y back, alineado al prototipo Tailwind y a la rúbrica académica. Sin cajas negras.

Datos

Modelo relacional multi-tenant. Base sólida para CRM y finanzas.

Async

Redis + BullMQ

Colas para PDF, IA y email sin congelar la interfaz.

IA

OpenAI + RAG

Desde Release 2. Knowledge aislado por agencia (agencyId).

Auth

JWT + RBAC

Roles asesor, gerente/admin y viajero con permisos por módulo.

Storage

Object storage

Documentos del viaje, cotizaciones PDF e itinerarios.

DevSecOps

CI + monorepo

GitHub Actions, health checks y auditoría de acciones sensibles.

Por qué no Django / Laravel / Firebase

Los evaluamos. Elegimos este stack por alineación al prototipo React/Tailwind, consultas relacionales fuertes para CRM y transparencia académica.

Criterio de decisión

Velocidad del equipo + demo piloto + mantenibilidad. No moda tecnológica.

08 · Ventaja competitiva

Por qué ganamos el pitch frente a “otro chatbot” o “otro CRM”

1. Loop cerrado

WhatsApp-first + portal + CRM + cotizador en un solo producto.

2. IA con knowledge propio

No un copiloto genérico: políticas, tono y FAQs por agencia (RAG + agencyId).

3. Marca blanca real

Logo, dominio, app — diferencial comercial fuerte en LATAM.

4. Stack transparente

Arquitectura moderna y documentada (ventaja académica y de confianza).

5. Arquitectura asíncrona

Colas para PDF/IA/email: evitamos la latencia típica de “smart import / copiloto” que congela la UI en competidores.

No competimos por ser el chatbot más rápido ni el CRM más bonito — competimos por ser el sistema operativo completo que hoy ninguna agencia LATAM tiene.
