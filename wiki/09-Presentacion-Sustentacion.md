# Presentación / Sustentación — Sprint 0

Formato sugerido: **pitch 8–12 min** + Q&A.

## Guion (obligatorios del documento maestro)

### 1. Problemática (con cifras)
- Agencias pierden leads por respuestas lentas (el viajero cotiza con varias agencias a la vez).
- Cotización manual multi-sistema (PDF, WhatsApp, Excel, reservas).
- Sin seguimiento ni métricas de conversión/CAC.
- Citar 2–3 estadísticas actualizadas en la lámina (turismo digital LATAM / WhatsApp commerce / pymes turismo). *Actualizar fuentes el día del pitch.*

### 2. Solución TravelOS AI
- Ecosistema SO de agencia (no CRM/chatbot/cotizador aislado).
- MVP piloto: CRM + cotizador IA + itinerarios + portal + dashboard.
- Marca blanca + IA que aprende tono/políticas de cada agencia.

### 3. Arquitectura y tecnologías
- Diagrama de componentes (Wiki Arquitectura).
- Stack: Next.js, NestJS, PostgreSQL, Redis/BullMQ, OpenAI, R2/S3, GitHub Actions.

### 4. Funcionalidades principales (MVP)
- Priorización de leads, cotización NL, itinerario, portal viajero, KPIs.

### 5. Prototipos
- Mostrar pantallas en vivo o screenshots (`docs/mockups/screenshots`).
- Link prototipo origen / demo local Vite.

### 6. Competencia y ventaja
- TravelJoy, Travefy, chatbots puntuales.
- Ventaja: ecosistema + WhatsApp-first LATAM + IA por agencia + portal viajero integrado.
