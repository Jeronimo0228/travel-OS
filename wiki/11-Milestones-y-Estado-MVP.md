# Milestones y estado del MVP

Los milestones de GitHub cierran cada sprint y declaran el **estado del MVP** con requisitos técnicos completados.

| Milestone | Objetivo técnico | % MVP (alcance acordado) | Criterio de cierre |
|---|---|---:|---|
| **Sprint 0** — Definición | Wiki, arquitectura, mockups, backlog, actas | 0% código | Artefactos Sprint 0 aprobados en Wiki |
| **Sprint 1** — Fundación + CRM | Auth, tenancy, RBAC, leads, pipeline, tareas, CI | ~25% | HUs Sprint 1 Done + demo CRM |
| **Sprint 2** — Cotizador + Itinerarios | NL quote, PDF, itinerario, catálogo seed, knowledge | ~65% | Demo cotización→itinerario→PDF |
| **Sprint 3** — Portal + Insights + Piloto | Portal viajero, dashboard, automatización follow-up | ~100% MVP | Piloto interno + checklist UAT PO |
